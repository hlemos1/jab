# Judge walkthrough · 90 seconds

- **0–10s:** Enter a display name. Explain that this is a standalone demonstrator, with synthetic sensor telemetry.
- **10–30s:** Open the Battle of the Day. Show six station types and an illustrative non-uniform journey, start the accelerated replay and inspect the live event stream. Skip to results if desired.
- **30–45s:** Show the server-calculated illustrative score, credited demo JAB and session digest.
- **45–60s:** Request the optional Devnet receipt. If confirmed, open the Explorer; if unavailable, state clearly that the public faucet/RPC is unavailable. Never substitute an unrelated transaction.
- **60–75s:** Redeem the fictional guest pass. Show the deducted balance and history.
- **75–90s:** In the lab, submit an inconsistent session and replay an accepted session. Show rejection and no second reward.

The demo's engineering claim: a complete simulated training-data pipeline with durable state, explicit validation, exactly-once session credits and a real Devnet receipt integration path. It does not claim live hardware proof, token minting or production-ready antifraud.
